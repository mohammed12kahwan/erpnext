========================================
OPTION 1: DIRECT DEVELOPMENT (RECOMMENDED)
========================================

Step 1: Install Python 3.10+
- Download: https://python.org
- Install it

Step 2: Install Node.js
- Download: https://nodejs.org
- Install it

Step 3: Open PowerShell and type:

pip install frappe-bench

Step 4: Go to project folder:

cd C:\Users\ADMIN\erpnext-dev

Step 5: Initialize Bench:

bench init frappe-bench
cd frappe-bench

Step 6: Get Frappe and ERPNext:

bench get-app https://github.com/frappe/frappe.git --branch version-15
bench get-app https://github.com/frappe/erpnext.git --branch version-15

Step 7: Create site:

bench new-site development.local --db-type=mariadb

Step 8: Install ERPNext:

bench --site development.local install-app erpnext

Step 9: Start server:

bench start

Step 10: Open browser:

http://localhost:8000

========================================
OPTION 2: DOCKER (FASTER)
========================================

Just run in PowerShell:

docker run -d --name erpnext_dev -p 8000:8000 -e DB_HOST=host.docker.internal -e DB_USER=erpnext -e DB_PASSWORD=erpnext -e REDIS_CACHE=host.docker.internal:6379 frappe/erpnext:v15

Wait 2-3 minutes, then open:

http://localhost:8000
