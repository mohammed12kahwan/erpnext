===============================================
TROUBLESHOOTING
===============================================

Q: Source code extraction fails?
A: Make sure erpnext_dev container is running:
   docker ps | findstr erpnext_dev

Q: Git push fails?
A: Configure Git credentials:
   git config --global user.name "Your Name"
   git config --global user.email "email@example.com"

Q: Changes not showing in browser?
A: Try:
   1. Hard refresh browser (Ctrl+Shift+R)
   2. Clear browser cache
   3. Restart Docker container: docker restart erpnext_dev

Q: How to switch between GitHub branches?
A: git checkout branch-name
